# Project assurance directory

This directory contains the project's machine-readable assurance profile and catalog, detailed policy, schemas, verifier contracts/tools, installed-template provenance, and retained evidence records. Human product and architecture decisions live under `docs/`; compact agent instructions live in root `AGENTS.md`.

Draft scaffolding is not approval. The project profile and catalog identify owners and applicability. Verification results, reviews, waivers, and effect manifests must conform to their schemas and must never be fabricated or retroactively rewritten.

Update this package through `assurance-system-manifest.json` and the upstream installation/update procedure. Do not overwrite project-owned decisions or historical evidence.
